# Guild Grudge

## Settings
- Prefer a setting over a hard-coded choice. When a behaviour is a matter of taste (a cooldown, an alert, a sound, a button), add it to the Settings panel in `GuildGrudge/Options.lua` with a default in `DEFAULTS` in `GuildGrudge/Core.lua`.
- Give every slider a label formatter, so the player can see its current value.
